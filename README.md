# VR Training Demo

Учебный VR-проект на Unity с двумя сценами: лобби и тренировкой «Проверка документов».

## Запуск

1. Откройте папку проекта в Unity Hub (Unity 2022.3.62f3 LTS).
2. Дождитесь импорта пакетов. При первом открытии редактор создаст сцены `Lobby` и `Training` из примитивов Unity и добавит их в Build Settings.
3. Нажмите Play. В лобби нажмите кнопку на панели или клавишу E.

Проект рассчитан на URP. Для VR включите OpenXR в Project Settings → XR Plug-in Management и настройте профиль контроллеров своего шлема. Без шлема доступен desktop-режим: WASD, мышь, E для взаимодействия, Esc для освобождения курсора. На геймпаде доступны стики и кнопка взаимодействия.

## Сценарий

Тренировка включает три группы по три действия: «Подготовка», «Проверка документов», «Подтверждение». Шаги проверяют подход в зону, захват нужного предмета и нажатие нужной кнопки. Порядок контролируется. Ошибка отмечается в результате; нарушение порядка завершает текущую группу. В финале показан статус каждого шага и доступны повтор и возврат в лобби.

## Архитектура

- `ScenarioDefinition` хранит сценарий как данные, отдельно от логики прохождения.
- `ScenarioRunner` проверяет действия, порядок, статусы шагов и переходы между группами.
- `VRPlayerController` объединяет desktop-ввод и чтение позы/кнопок XR-устройств.
- `InteractableTarget` связывает объекты сцены с командами сценария.
- `OutlineHighlight` рисует контур наведённого предмета собственным URP-шейдером.
- `DemoSceneBuilder` создаёт наглядные сцены из встроенных примитивов Unity.
- `ProjectSetup` генерирует сцены и URP-конфигурацию при первом открытии проекта.

Основные зависимости направлены от ввода и объектов сцены к `ScenarioRunner`; данные сценария не зависят от UI или XR. Новые сценарии можно добавлять через `ScenarioDefinition`, не меняя механику проверки.

## Управление

| Действие | Desktop | VR |
| --- | --- | --- |
| Перемещение | WASD | левый стик |
| Осмотр | мышь | поворот головы |
| Взаимодействие | E / ЛКМ | триггер правого контроллера |
| Взять предмет | E рядом с предметом | триггер рядом с предметом |

## Структура

`Assets/Scripts` содержит runtime-код, `Assets/Editor` — генератор сцен проекта, `ProjectSettings` — настройки проекта Unity. Сцены намеренно собраны из примитивов, чтобы проект не зависел от сторонних визуальных ассетов.
