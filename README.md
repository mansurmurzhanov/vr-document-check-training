# VR-тренажёр: проверка документов

Учебный VR-проект на Unity 2022.3.62f3 LTS: сцена Lobby запускает тренировку проверки документов, в которой нужно пройти три последовательные группы действий. В лобби нажмите кнопку, Enter или пробел; без шлема доступны WASD, мышь, E и Esc, в VR — перемещение левым стиком, поворот головы и триггер правого контроллера. Для запуска откройте папку проекта через Unity Hub и нажмите Play на сцене Lobby.

Архитектура разделяет данные сценария (`ScenarioDefinition`), проверку порядка и результатов (`ScenarioRunner`), управление игроком (`VRPlayerController`) и интерактивные объекты (`InteractableTarget`). Сцены построены из примитивов Unity и используют URP; собственный `OutlineHighlight` подсвечивает доступные объекты. Новые сценарии можно добавлять как данные без изменения логики ввода и визуализации.
